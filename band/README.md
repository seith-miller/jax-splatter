# band

The performing unit: who plays, what they play, arrangements for live
performance, and the practical kit (inputs, monitoring, stage plots).

- [instruments/](instruments/) — the custom kit, one sheet per instrument.
- [charts/](charts/) — the written parts: one performance map per song.
  [chairs.md](charts/chairs.md) defines the nine-chair touring ensemble every
  song is charted for; a given night plays a subset of it.
