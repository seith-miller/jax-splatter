# The X mark — reference

Typewriter letters with one big X in a different face, over a splat mass
built along the text until it encloses it (Jax, 2026-09-30: "most of the
text the typewriter font, just the X larger and in the first font; the
text always fully surrounded by the splatter"). Letters Special Elite
(Apache 2.0) in One-Sheet; the X Rubik Spray Paint (OFL) in Splatter Pink
at 1.55× the cap height, centred on it; alternate X in Rubik Distressed.
Generated by `tools/x-mark.py`, deterministic per seed.

| File | What |
|---|---|
| `x-mark-{line,jax,stack}_spray_s7.png` | mark + mass, transparent — the production source |
| `*_framed.png` | the same on Night, 1920×1080, for review |
| `*_distressed_*` | the alternate X face |

Reference, not a release. A picked form becomes the candidate for
**JAX-A013 merch-logotype v1**; the round-1 production files get rebuilt
in it. The mass is the paintball-photo splat — rights gate still open for
sold goods.
