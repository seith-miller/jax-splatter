# The ransom-note merch mark — reference

Cut-out letters the way the Punk Freud graphic did them
(interzone/events/multipass/promo/punk_freud_starburst.py): each letter on
its own tile in a different face, a different size, torn corners, a lean,
pasted along a rough baseline. Tiles Splatter Pink, letters Night (Jax,
2026-09-30: every letter pink). Generated by `tools/ransom-mark.py`,
deterministic per seed — every seed is a different throw.

| File | What |
|---|---|
| `ransom-line_s7.png` | JAX SPLATTER, one line — RGBA, mark only, 3.8k px wide |
| `ransom-jax_s7.png` | JAX — the button / avatar form |
| `ransom-stack_s7.png` | JAX over SPLATTER |
| `*_s7_on-splat.png` | each over the key-art splat mass on Night, 1920×1080 |
| `*_s23.png` | a second throw, marks only |

Reference, not a release. If Jax picks one it becomes the candidate for
**JAX-A013 merch-logotype v1** (its own release; A002 stays the site mark)
and the round-1 production files get rebuilt in it. The splat underneath is
the paintball-photo mass — rights gate still open for sold goods.
