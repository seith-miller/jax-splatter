# The stage vision — the North Star

Jax Splatter is a music **entertainment project intended to make money**.
The brand hits the ground running; production elements roll out over time.
This document is the fully-realized picture everything builds toward —
custom instruments, lights, choreo, video, staging. Funds that come in are
reinvested against this vision, phase by phase.

Ratified operating model (Jax, 2026-09-08):

1. **Capture the vision early** — this doc, before the builds.
2. **Phase the realization** — each phase is what the next show can carry;
   nothing waits for the whole vision to exist.
3. **Reinvest revenue** — booking/merch income funds the next phase
   (tracked against band/instruments/BUDGET.md and siblings).
