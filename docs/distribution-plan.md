# Distribution — we need a plan

**Status: needed, not written.** The act has no route from a finished track to
any store or streaming service. This file records the need and the decisions
the plan must make; when the plan is written it replaces this stub and its
decisions get ratified in [decisions.md](decisions.md).

## What already exists

[accounts-inventory.md](accounts-inventory.md) Wave 4 sketches the mechanism:
**DistroKid** as the distributor — one upload feeds Spotify, Apple, Tidal,
Amazon, and YouTube Music, and the Spotify artist profile is *created by* the
first release. That's a tool choice, not a plan.

## What the plan must decide

- **Label name.** Beatport — the DJ store — only takes releases through a
  label; distributors register one on your behalf, so a name has to be
  chosen. DistroKid's Beatport delivery is electronic-genres-only and by
  request.
- **Store list.** Which of streaming (Spotify et al.), DJ stores (Beatport,
  Traxsource, Juno), and direct (Bandcamp) the first release targets, and in
  what order.
- **Licensing.** Originals are clean. Covers need mechanical licensing
  (DistroKid offers it). Bootleg edits of other people's tracks cannot be
  distributed at all — they stay in the live sets.
- **Timing.** Distribution is created by the first release (that's why Wave 4
  is deferred), so the plan hangs off the first finished original, not a
  calendar date.
