# Setlist builder

Live tool (Claude artifact, per the choreo-apps pattern):
https://claude.ai/code/artifact/be908126-c2bb-4b81-94e6-6d113f0813df

Drag-to-order setlist with a running-time meter against the 20:00 slot /
45:00 prepared targets. Tracks carry BPM + key (machine-estimated from the
bounces via librosa; editable). SAVE republishes the page — the artifact
is the setlist of record; `setlist.html` here is a code snapshot, not the
live state.
